# Fredasil, C.A. - Servicio Técnico Eléctrico

Sitio web profesional para Fredasil, C.A., especialistas en instalaciones eléctricas residenciales, comerciales e industriales.

## 🚀 Características
- **Diseño Premium**: Interfaz moderna, limpia y responsive.
- **Optimización**: Construido con Vite para un rendimiento ultrarrápido.
- **Contacto Directo**: Integración con WhatsApp para presupuestos y consultas.
- **SEO Ready**: Etiquetas meta y estructura semántica.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Vanilla CSS)
- JavaScript (ES6+)
- [Vite](https://vitejs.dev/)
- [Lucide Icons](https://lucide.dev/)

## 📦 Instalación y Desarrollo
1. Clona el repositorio.
2. Instala las dependencias: `npm install`
3. Inicia el servidor de desarrollo: `npm run dev`
4. Para producción: `npm run build`

## 🌐 Despliegue en Vercel
Este proyecto está optimizado para Vercel. Simplemente importa el repositorio desde el panel de Vercel y se configurará automáticamente.
